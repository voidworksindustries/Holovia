Patch Notes

Latest update notes for Holovia.

Version 1.9.0.3

Latest

Holovia 1.9.0.3 focuses on significantly faster startup times and correcting the version information displayed in the game.

Improvements & Changes

  • Significantly reduced the time required to start the game
  • Improved initialization performance during startup
  • Updated the version code displayed in the settings menu

Bug Fixes

  • Fixed an issue where the displayed version code was not updated correctly
  • Fixed an issue that could cause extremely long startup times

Private Development

  • Internal development and testing changes

  • Preparation for the 1.9.0.3 public release
  • Various internal maintenance changes

Version 1.9.0.1

Holovia 1.9.0.1 focuses on online compatibility, Challenge Race reliability, improved coin feedback, and loading and startup stability.

Improvements & Changes

  • Improved loading, startup, settings, and update-screen behaviour
  • Added further localization and interface refinements across race and online systems

Bug Fixes

  • Fixed inactive Challenge Race runs remaining active and affecting results or rewards
  • Fixed several Challenge Race join, reward, cleanup, and reconnection issues
  • Fixed overlapping coin pickup sounds during fast collection
  • Fixed multiple online, menu, loading, and stability issues

Version 1.9

Holovia 1.9 introduces Challenge Races, Replay Runs, live two-player Online Multiplayer, a new Race Hub, dynamic environment transitions, the new Cluster Shooter Wall, eleven new daily mission types, and major gameplay, leaderboard, localization, replay, and stability improvements.

New Features

  • Challenge Races have been added, allowing players to create public or private races for others to compete in
  • Challenge creators can choose the game mode, revive rules, visibility, and an optional winner coin prize
  • Challenges can be joined through Explore, an exact race code, or a shared Holovia link
  • Replay Runs have been added, allowing players to race against ghosts from their own completed runs
  • Compatible cloud replays from the global leaderboard can now be opened directly as races
  • Live two-player Online Multiplayer has been added with lobby creation, lobby codes, ready states, and synchronized race starts
  • A new Race Hub now provides access to Challenge Race, Replay Run, and Online Multiplayer
  • Dedicated race intros, progress displays, result screens, win and loss notifications, and reward claiming have been added
  • Daylight, Sunset, and Night can now transition dynamically during gameplay
  • The new Cluster Shooter Wall launches groups of shooter pieces in waves and appears later in a run
  • Eleven new daily mission types have been added across shooting, shields, dashing, shifting walls, streaks, coins, revives, movement, and Replay Runs
  • Longest mission streak is now tracked in player statistics
  • A new scoreboard Search flow has been added to make players easier to find
  • Replay ghosts now include a dedicated marker and live distance display

Improvements & Changes

  • Wall generation now uses a chunk-based system to keep connected wall sequences stable across normal gameplay, replays, and multiplayer
  • Replay and multiplayer races now preserve wall decisions, random streams, difficulty progress, and special-wall state more accurately
  • Online Multiplayer gives both players the same synchronized seed, wall layout, start time, and race conditions
  • Opponent movement, dashes, and flow feedback are synchronized through a live remote ghost
  • Online Multiplayer is non-ranked and disables perks, revives, rewards, replay saving, and high-score submission for fair play
  • Public Challenge Races can now be filtered, refreshed, and loaded progressively while browsing
  • Race Hub lists now use caching, background refreshes, row pooling, and clearer loading, empty, and connection-error states
  • Replay lists now support sorting and keep the newest 50 local runs to control storage use
  • Cloud replay files are cached locally for faster repeat access and cleaned up when no longer needed
  • Replay files now preserve more run identity, score, wall state, revive, perk, and version information
  • Replay ghost movement, dash timing, chunk continuation, visibility, hole stops, and wall matching have been refined
  • Race pause, quit, restart, HUD, intro, game-over, and result routing now remain separate from normal runs
  • Race rewards only appear when earned and result scores are placed consistently for both players
  • Shooter pieces now provide clearer danger icons, launch feedback, collision volumes, and lane-aware hit detection
  • The Cluster Shooter Wall uses its own material, launch cue, and rocket-flight audio
  • Wall highlighting has been rebuilt with cleaner overlays, outlines, priority handling, and pass feedback
  • Power-up pickup protection has been improved during fast movement and close wall interactions
  • Wall progression, unlock timing, special-wall selection, revive continuation, and late-run difficulty have received further balancing
  • Camera shake, haptics, dash effects, player animations, and wall-pass feedback have been polished
  • Sky, horizon, fog, terrain, floor, reflections, ambience, and lighting now blend more smoothly between environments
  • Player details now display the Player ID using localized labels
  • Race, high-score, and default notifications can now use distinct sounds with a safe fallback
  • Challenge Race, Replay Run, Online Multiplayer, result, validation, and game-mode text has been localized across all supported languages
  • Race menus and result screens have received new materials, colors, icons, loading states, responsive layouts, and navigation feedback
  • The outdated exact-score and twist-dash daily missions have been retired

Bug Fixes

  • Fixed multiple cases where replay ghosts could desynchronize, snap, disappear incorrectly, stop at the wrong wall, or react to live player movement
  • Fixed invalid, incomplete, or incompatible replay files being allowed to start a race
  • Fixed several replay visibility, wall-grid, revive, score, result, and cleanup issues
  • Fixed multiplayer join timing, lobby listener, same-seed generation, ready-state, disconnect, result, cleanup, and host or client asymmetry issues
  • Fixed race screens showing stale information, incorrect scores, incorrect reward states, missing localization, or misleading connection errors
  • Fixed several shooter-piece collision, warning, lane, wall-impact, audio-tail, and cleanup issues
  • Fixed interrupted environment transitions and several background style continuity issues
  • Fixed multiple wall generation, power-up, revive continuation, and special-wall state issues
  • Fixed multiple Race Hub dropdown, tab, slider, button, layout, loading, and navigation issues
  • Reduced unnecessary Firebase reads and improved backend validation, retries, session cleanup, and security rules
  • Improved multiplayer lifecycle handling when a player leaves, disconnects, is removed, or finishes a race
  • Multiple additional gameplay, interface, localization, performance, and stability fixes

Version 1.8.0.5

Holovia 1.8.0.5 focuses on a major onboarding overhaul, clearer movement guidance, stronger dash feedback, improved wall balancing, new skins, leaderboard upgrades, and multiple user interface improvements.

New Features

  • New hold-swipe onboarding lesson added with guided practice walls
  • New post-tutorial transition wall added to improve the move into normal gameplay
  • Added six new skins: Crysim, Trysim, Brysim, Grysim, Prysim, and Vrysim
  • Leaderboard player profiles now display games played and last online information
  • New startup tips and gameplay hints have been added

Improvements & Changes

  • Tutorial completely redesigned into a shorter and more focused onboarding experience
  • Tutorial now focuses on normal movement and dash-only walls before entering the main game
  • Added dedicated hold-swipe teaching with guided practice, movement demonstrations, and release prompts
  • Added slow-motion assistance during important tutorial and dash learning moments
  • Dash guidance has been improved with stronger visual, haptic, camera, and player feedback
  • Dash opportunities now provide clearer cues during normal gameplay
  • Movement previews now better display nearby valid cells and longer swipe paths
  • Added haptic feedback for repeated hold-swipe movement
  • Wall progression has been rebalanced with smoother score-based unlocks and difficulty ramps
  • Early-game wall patterns have been redesigned to be easier to read
  • Added new basic wall variations for early gameplay
  • Reduced the frequency of fake walls
  • Shooter walls now provide clearer warning prompts before firing
  • Added proximity-based haptic feedback for incoming shooter pieces
  • Notification system improved with custom progress bars and persistent progress notifications
  • Queued notifications can now refresh more cleanly while playing
  • Notification hide animations have been cleaned up
  • Game-over messages now better match the player’s progress and avoid misleading restart text
  • Global leaderboard row interface improved with expandable player details and better click handling
  • Shop items are now automatically sorted by price
  • Shop requirement and currency messages have been improved
  • Improved localization support across shop, notifications, and gameplay feedback

Bug Fixes

  • Fixed multiple tutorial flow and progression issues
  • Fixed several notification refresh and display issues
  • Fixed various wall generation and balancing issues
  • Fixed multiple leaderboard interface issues
  • Fixed several shop requirement and unlock display issues
  • Fixed various localization and text display issues
  • Multiple gameplay, UI, and stability fixes

  • Fixed an issue where shifting walls could sometimes spawn without holes

Version 1.8

Holovia 1.8 brings iOS support, Game Center integration, new environments (Daylight, Sunset, Night), a full performance overhaul, smoother controls, a new streak system, and major gameplay improvements. Plus dozens of bug fixes and visual upgrades.

New Features

  • iOS support — Holovia is now available on the App Store
  • Game Center integration — leaderboards and future challenges enabled
  • New environments and styles: Daylight, Sunset, and Night, including new terrain variations
  • Mission rewards system — collect rewards directly from the mission menu
  • Unique player ID system — enables skin ownership and reward tracking
  • Animated UI buttons — all buttons now respond visually to input
  • New loading screen
  • Credits screen added
  • Birds added for ambient world detail
  • Firebase integration for improved feedback and analytics
  • Bug reporting system — report issues directly from the settings menu
  • Notifications system added
  • New streak system — build streaks for bonus points and rewards
  • Cube personality added and visible in the menu

Improvements & Changes

  • Adaptive performance system automatically adjusts performance based on device
  • Manual performance settings added in the redesigned settings menu
  • Major performance overhaul, especially for low-end devices
  • Input smoothing added to reduce stutter and improve responsiveness
  • Improved haptic feedback on iOS
  • Wall generator can now spawn multiple walls at once
  • Visual enhancements including deeper gridline colors
  • Twisting walls now change colour during rotation
  • New and improved high-speed effects
  • Pause button moved to a new location
  • Power-up UI moved behind the pause menu
  • 2x indicator moved behind the pause menu
  • Mission text size adjusted
  • All walls and speeds have been rebalanced
  • Distance between grid switches has been reduced
  • Classic mode no longer unlocks new gamemodes, allowing it to remain a practice-focused mode
  • Some skins now require a high score, streak, or games played to unlock
  • Walls are now slightly slower directly after a revive, giving players a fairer chance to recover
  • Music now continues correctly after a restart
  • Early-run flavour text has been added
  • A larger reward has been added for completing the streak
  • Some cubes now have faces for added personality

Bug Fixes

  • Shooter pieces no longer shoot through other walls
  • You can no longer shoot through high-speed moving walls
  • Dash through 10 red walls now works properly
  • Side-shifting walls no longer move after starting a dash
  • Shifting walls now always show a green indicator hole
  • Rotating walls no longer show a player highlight
  • Power-ups no longer get collected unless the player actually catches them
  • You can no longer dash through a twisting wall while it is twisting
  • Twisting walls no longer kill the player during the tutorial
  • Fire has been removed from twisting 5x5 walls
  • Shooter pieces now only fire when in front of the player, unless they are self-shooting wall pieces
